RSAP

Randomly Select A Person

RSAP 是一款轻量本地随机选人工具，用于课堂点名、名单抽签、随机分组。

所有名单保存在本机，无需联网上传，保护你的隐私。C++开发，轻量快速，无广告。

本地运行，不上传名单
导入文本名单，一键抽取
支持去重 / 自定义抽取数量
